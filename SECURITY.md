# Security reporting

Report security issues privately to **thecarpgalilee@gmail.com**. Include reproduction details without passwords, tokens, customer data or private signing material. Do not publish exploitable details in GitHub issues.

This static site needs no production credentials. Never commit secrets, application environment files, signing keys, internal diagnostics or user data. Review both staged changes and the new commit before pushing. The automated validator detects common credential patterns but cannot prove that all operational information is safe to disclose.
